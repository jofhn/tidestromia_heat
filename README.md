# tidestromia_heat

Code for the analyses in Feehan et al. (bioRxiv 2026.07.22.740203), on heat
adaptation in *Tidestromia oblongifolia*.

`wgs/reference_panel.md` covers the reference panel resequencing: read
processing, variant calling and filtering, then PCA and F_ST. Other sections
will be added as they're written.

Raw reads will be released at NCBI SRA on publication. The AmA10 assembly and
annotation are from Prado et al. 2025 (Curr Biol 35:5502-5520).
